# Qlik Sense / Qlik Cloud

> Qlik Cloud is a business intelligence, data integration and AI analytics platform.
> It exposes a large, fully machine-readable API surface: 78 OpenAPI 3.0.0 documents
> covering 681 REST operations, 29 AsyncAPI 3.0.0 event documents, an OpenRPC 1.0.0
> document for the QIX Associative Engine WebSocket API, 39 published JSON Schemas for
> Qlik Talend Cloud pipelines, and a proto3 gRPC contract for the engine's Server-Side
> Extension protocol. A first-party remote MCP server has been generally available since
> 2026-02-10.

This file was GENERATED by API Evangelist from Qlik's own published specifications and
documentation on 2026-08-29. Qlik does not serve an llms.txt of its own
(https://qlik.dev/llms.txt returned 404). Qlik DOES serve a markdown twin of every
documentation page: append `.md` to any qlik.dev page path (e.g.
https://qlik.dev/apis/rest/rate-limiting.md) to get clean markdown with `source` and
`last_updated` frontmatter.

## Base URL

All REST calls go to `https://{tenant}.{region}.qlikcloud.com`, where `{tenant}` is your
tenant name and `{region}` is its hosting region (e.g. `us`, `eu`). There is no shared
public host — every call is tenant-scoped.

## Agents

- [Qlik MCP Server](https://www.qlik.com/us/products/model-context-protocol): remote MCP endpoint at `<your-tenant-url>/api/ai/mcp`. OAuth 2.0 only; no anonymous access. GA 2026-02-10. Qlik states 70+ tools across 9 categories; no public tool manifest is published.
- [Qlik Agentic Skills](https://github.com/qlik-oss/agentic-skills): Qlik's public Agent Skills hub, SKILL.md format, installable with `npx skills add qlik-oss/agentic-skills`.
- [MCP telemetry contract](https://qlik.dev/apis/event/ai/mcps/): AsyncAPI 3.0.0 for com.qlik.ai.mcp.tool.executed and com.qlik.ai.mcp.tool.calls.aggregated.
- No A2A agent card is served (/.well-known/agent-card.json returns 404).

## Non-REST contracts

- [QIX Engine API](https://qlik.dev/apis/json-rpc/qix): JSON-RPC over WebSocket, published as OpenRPC 1.0.0 at https://qlik.dev/specs/json-rpc/qix.json
- [Events](https://qlik.dev/apis/event/): 29 AsyncAPI 3.0.0 documents at https://qlik.dev/specs/event/<name>.json, CloudEvents 1.0 payloads, delivered by webhook.
- [Server-Side Extension](https://github.com/qlik-oss/server-side-extension): proto3 gRPC service for extending the engine with external compute (R, Python).
- [Declarative pipeline schemas](https://github.com/qlik-oss/schemas): 39 JSON Schemas for Qlik Talend Cloud projects and tasks.

## Known gaps

An agent should know these before generating a client:

- The published OpenAPI documents declare NO securitySchemes and NO security requirements on any of the 681 operations. Add the `Authorization: Bearer` header yourself.
- 177 of 681 operations have no operationId. Address them by method and path.
- No idempotency-key support anywhere on the write surface.
- Errors use a JSON:API-style `{"errors":[...]}` envelope, not RFC 9457 problem+json.
- No RateLimit-* quota headers on successful responses — only `Retry-After` on the 429.
