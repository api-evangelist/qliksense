Qlik Cloud has introduced two new event APIs for tracking environment and space lifecycle changes. The Environments API provides events for creation, deletion, and configuration updates, while the Spaces API covers space management including creation, deletion, metadata updates, assignment changes, sharing events, and settings modifications. These capabilities enable developers to automate tenant management workflows and maintain audit logs of system changes.
