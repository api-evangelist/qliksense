Qlik has released four new REST APIs for managing on-demand analytics generation (ODAG) workflows in Qlik Cloud. These APIs enable organizations to programmatically create ODAG links and automate operations like renaming, reloading, and managing generated applications without manual intervention. The APIs cover apps, links, requests, and settings, and are designed for high-volume analytics generation and integration with automated workflows and orchestration platforms.
